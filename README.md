# Faculty-Course-Evaluation
This project is a simple survey evaluation system for institutions like universities, high schools, etc. Students evaluate their instructors on areas where they can improve. The school administration can also identify competent staff to keep or let go.

## Getting Started
A minimal Flask application is included as a starting point. To run the development server:

1. Ensure you have Python 3 installed.
2. (Optional) Create and activate a virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install flask
   ```
4. Start the server:
   ```bash
   python src/app.py
   ```
5. Open your browser at [http://localhost:5000](http://localhost:5000) to see the welcome page.

## Project Structure
- `src/` - source code for the Flask application
- `tests/` - directory for test modules

Feel free to extend this starter project with additional functionality as needed.
